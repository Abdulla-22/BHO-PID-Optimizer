# README animation

`bho-workflow.gif` is a looping explanation of the project's optimization and
control workflow. `bho-workflow-static.png` provides a still version. Both are
original diagrams generated by [`generate_readme_animation.py`](../../scripts/generate_readme_animation.py)
and are covered by the repository's [MIT license](../../LICENSE).

The gain-space projection, event-horizon illustration and response curves are
schematic. They are not recorded optimization runs, simulation results or motor
measurements. The 2D search view represents two gain coordinates; the optimizer
uses the gain vector required by the selected PI, PD or PID controller.

To regenerate from the repository root:

```powershell
python -m pip install Pillow
python scripts/generate_readme_animation.py
```

The script uses an installed system font (Segoe UI on Windows, DejaVu Sans on
Linux, or Arial on macOS). It does not include or distribute font files. Layout
and text widths can vary by font; visually inspect the output after regeneration.
